LISTA DE REQUERIMIENTOS DEL CLIENTE

ALCANCE DEL SISTEMA:
El sistema sera una agenda personal de retiros la cual permitira que el usuario registre manualmente los retiros grupales hechos y por hacer, organizar su informacion, consultar cronogramas y recibir recordatorios.
El sistema solo permitira la informacion  registrada por el usuario ymantendra la informacion cargada de forma privada.

Requerimientos funcionales(RF)
GESTION DE RETIROS
RF1 -- Registrar Retiro
-Nombre.
-Contacto del organizador.
-Fecha de inicio.
-Duración.
-Disponibilidad.
-Estado: por realizar o realizado.
-Ubicación geográfica.
-fotos de los lugares y ubicaciones
-Servicios incluidos y no incluidos.
-Nivel de privacidad.
-Nivel de atención.
-Cronograma de actividades ofrecidas.
-Intensidad de las actividades.
-Objetivos o beneficios esperados.
-Público destinatario: hombres, mujeres o mixto.
-Cantidad de personas: grupal o individual.
-Clima esperado
-Precio.
-Política de cancelación.
-Descripcion general
-comentario adicional
-Puntuación.
-Forma de pago.
-Fechas disponibles.
-Reseñas u opiniones.
-Gastos asociados

RF2 -- Modificar retiro 
El sistena debe permitir modificar la informacion de un retiro.

RF3 -- Eliminar retiro
El sistema debe permitir eliminar un retiro registrado.

RF4 -- Consultar retiro
El sistema debe permitir consultar toda la información registrada de un retiro.

BUSQUEDA
RF -- Busqueda de retiro
El sistema debe permitir buscar los retiros registrados

RF -- filtrar la busqueda de retiros registrados
El sistema debe poder filtrar la búsqueda de retiros mediante uno o más atributos.

RF -- busqueda sin filtros
Si no se aplican filtros, el sistema debe permitir ordenar los retiros registrados aleatoriamente o con los más recientes primero 

AGENDA
RF -- El sistema debe ofrecer al usuario agendar un retiro y cargarlo en la agenda.

RF -- Visualizacion del calendario de retiros
El sistema debe mostrar los retiros registrados en un calendario.

RF -- Modificar agenda
El sistema debe permitir modificar la información de los retiros registrados en la agenda.

RF -- Eliminar retiro de la agenda
El sistema debe permitir quitar un retiro de la agenda.

NOTIFICACIONES
RF -- El sistema debe notificar al usuario antes de el inicio de cada retiro programado y también de sus actividades.

RF -- Configurar notificaciones
El sistema debe permitir al usuario configurar los recordatorios de los retiros y sus actividades.

RF -- Notificar actividades
El sistema debe notificar al usuario antes del inicio de las actividades programadas de un retiro.

RESEÑAS Y PUNTUACIONES
RF -- Registrar reseña
El sistema debe permitir al usuario registrar una reseña, comentario u opinión asociada a un retiro.

RF -- Consultar reseñas
El sistema debe permitir consultar todas las reseñas y opiniones registradas sobre los retiros.

RF -- Registrar puntuación
El sistema debe permitir al usuario asignar una puntuación a un retiro.

GESTIÓN DE GASTOS
RF -- Registrar gasto
El sistema debe permitir registrar gastos asociados a un retiro.

RF -- Consultar gastos
El sistema debe permitir consultar los gastos asociados a un retiro.

RF -- Consultar gastos totales
El sistema debe mostrar el total de gastos de un retiro.

RF -- Consultar gastos mensuales
El sistema debe permitir consultar los gastos de un retiro organizados por mes.
