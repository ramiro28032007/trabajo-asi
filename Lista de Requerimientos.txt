LISTA DE REQUERIMIENTOS DEL CLIENTE

Alcance del sistema
El sistema sera una agenda personal de retiros la cual permitira que el usuario registre manualmente los retiros grupales hechos y por hacer, organizar su informacion, consultar cronogramas y recibir recordatorios.
El sistema solo permitira la informacion  registrada por el usuario ymantendra la informacion cargada de forma privada.

Requerimientos funcionales(RF)

RF1 -- Registrar Retiro
El sistema debera permitir al usuario registrar de forma manual un retiro con la siguiente informacion:

-Nombre.
-Descripción.
-Objetivos o beneficios esperados.
-Fecha de inicio.
-Fecha de finalización.
-Duración.
-Estado: por realizar o realizado.
-Lugar y ubicación geográfica.
-Clima esperado.
-Datos de contacto del organizador.
-Público destinatario: hombres, mujeres o mixto.
-Actividades ofrecidas.
-Intensidad de las actividades.
-Cronograma.
-Servicios incluidos y no incluidos.
-Precio.
-Forma de pago.
-Política de cancelación.
-Nivel de privacidad.
-Nivel de atención.

RF2 -- Modificar retiro 
El sistena debe permitir modificar la informacion de un retiro.

RF3 -- Eliminar retiro
El sistema debe permitir eliminar un retiro registrado.

RF4 -- Consultar retiro
El sistema debe permitir consultar toda la información registrada de un retiro.

RF -- Busqueda y filtro de retiros registrados
El sistema debe permitir buscar y filtrar únicamente los retiros registrados por el usuario.

Los filtros podrán aplicarse por:

-Nombre.
-Fecha o periodo.
-Ubicación.
-Público destinatario.
-Precio.
-Nivel de privacidad.
-Nivel de atención.
-Estado: realizado o por realizar.

Si no se aplica ningún filtro, el sistema debe mostrar todos los retiros registrados.

RF6 -- Visualizacion del calendario de retiros
El sistema debe permitir visualizar los retiros registrados en un calendario, diferenciando los retiros realizados de los retiros por realizar.
También debe permitir consultar los retiros correspondientes a un mes o periodo determinado.

RF7 -- Gestionar cronograma de actividades
El sistema debe permitir registrar, modificar, eliminar y consultar las actividades correspondientes de retiro.

Para cada actividad se debe poder indicar:

-Nombre o descripción.
-Fecha.
-Horario de inicio.
-Horario de finalización.
-Nivel de intensidad.

RF8 -- Configurar notificaciones y recordatorios
El sistema debe permitir configurar notificaciones y recordatorios relacionados con:

-Próximos retiros.
-Inicio y finalización de actividades.
-Modificaciones en el cronograma.
-Fechas previstas de pago.
-Otras fechas importantes registradas por el usuario.

RF9 -- Registrar pagos
El sistema debe permitir registrar los pagos previstos y realizados a cada retiro.

Para cada pago se deberá indicar:

-Concepto.
-Monto.
-Fecha prevista.
-Fecha de realización.
-Forma de pago.
-Estado: pendiente o pagado.

RF10 -– Registrar gastos, aportes y donaciones

El sistema debe permitir registrar los gastos personales, aportes y donaciones voluntarias relacionados con un retiro.

Para cada movimiento se debe indicar:

-Concepto.
-Monto.
-Fecha.
-Tipo de movimiento: gasto, aporte o donación.
-Forma de pago.

RF11 –- Gestionar comprobantes
El sistema debe permitir adjuntar, consultar y descargar comprobantes asociados con pagos, gastos, aportes o donaciones registrados.

RF12 -– Gestionar acompañantes
El sistema debe permitir registrar, modificar, eliminar y consultar los acompañantes asociados con cada retiro.

RF13 –- Registrar valoración personal
El sistema debe permitir que el usuario registre una puntuación, un comentario y observaciones personales sobre un retiro realizado.
En los retiros pendientes, el usuario podrá registrar notas personales, pero no se calcularán calificaciones promedio ni se mostrarán reseñas de otros usuarios.

RF14 -– Consultar historial de retiros
El sistema deberá permitir consultar el historial de retiros realizados.

Para cada retiro del historial se podrá consultar:

-Información general.
-Cronograma de actividades.
-Pagos y gastos.
-Aportes y donaciones.
-Comprobantes.
-Acompañantes.
-Valoración personal.

Requerimientos no funcionales(RNF)

RNF1 -- Aplicacion movil
El sistema debe desarrollarse como una aplicación compatible con dispositivos móviles.

RN02 –- Registro manual
La información de los retiros debe ser ingresada manualmente por el usuario.

RN03 –- Uso personal
Cada usuario solamente podrá administrar sus propios retiros, cronogramas, pagos, acompañantes, notas y valoraciones.
